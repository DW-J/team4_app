# 마음풀이

전통 의례에서 영감을 얻은 브라우저 기반 창작 체험입니다. 스트레스 점수를 고르고, 감정 매듭 풀기·북과 흰 천·부적 따라 쓰기를 순서대로 경험합니다. 의학적 치료를 대신하지 않습니다.

## 실행

별도의 설치나 빌드 없이 정적 파일로 실행합니다. 프로젝트 폴더에서 예를 들어 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000
```

`index.html`, `styles.css`, `app.js`를 같은 경로로 배포하면 됩니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 시스템 글꼴을 사용합니다.

## 데이터와 현재 범위

입력한 별명과 감정은 진행 중인 브라우저 메모리에만 유지됩니다. 사용자가 완료 기록 저장을 선택하면 날짜와 전후 점수, 완료 여부를 해당 브라우저의 localStorage에 최대 30건 저장합니다. 완료 화면에서 기록을 삭제할 수 있습니다. 계정, 서버 저장, 기기 간 동기화는 없습니다. 브라우저 저장소를 지우면 기록도 삭제됩니다.

원본 프로토타입의 기능을 유지하도록 HTML, CSS, JavaScript를 분리한 초기 버전입니다. 매듭 건너뛰기 기능이 있지만 천 밀기와 부적 그리기는 포인터 조작이 필요합니다.
