# 마음풀이

전통 의례에서 영감을 얻은 브라우저 기반 창작 체험입니다. 스트레스 점수를 고르고, 감정 매듭 풀기·북과 흰 천·부적 따라 쓰기를 순서대로 경험합니다. 의학적 치료를 대신하지 않습니다.

## 실행

별도의 설치나 빌드 없이 정적 파일로 실행합니다. 프로젝트 폴더에서 예를 들어 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000
```

`index.html`, `styles.css`, `app.js`와 `assets/` 폴더를 함께 배포하면 됩니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 시스템 글꼴을 사용합니다.

## 데이터와 현재 범위

입력한 별명과 감정은 진행 중인 브라우저 메모리에만 유지됩니다. 사용자가 완료 기록 저장을 선택하면 날짜와 전후 점수, 완료 여부를 해당 브라우저의 localStorage에 최대 30건 저장합니다. 완료 화면에서 기록을 삭제할 수 있습니다. 계정, 서버 저장, 기기 간 동기화는 없습니다. 브라우저 저장소를 지우면 기록도 삭제됩니다.

원본 프로토타입의 기능을 유지하도록 HTML, CSS, JavaScript를 분리한 초기 버전입니다. 매듭 건너뛰기 기능이 있지만 천 밀기와 부적 그리기는 포인터 조작이 필요합니다.


## 진행 과정

1. 단일 HTML 프로토타입을 `index.html`, `styles.css`, `app.js`로 분리하고 정적 웹앱의 첫 버전을 GitHub에 올렸습니다. 기존의 감정 입력, 매듭 풀기, 북 두드리기와 흰 천 보내기, 부적 따라 쓰기, 완료 기록 기능을 유지했습니다.
2. 한옥 대문과 천하대장군·지하대장군이 등장하는 오프닝을 추가했습니다. 대문이 열리고 로고와 입장 버튼이 나타납니다.
3. 제공된 사진을 바탕으로 생성한 전신 인물 이미지를 오프닝 양옆에 배치하고, 화면 아래에 서 있는 모습으로 조정했습니다.
4. 인물에 커서를 올리거나 클릭 또는 키보드로 선택하면 말풍선이 나타나도록 했습니다. 입장하지 않고 10초가 지나면 오른쪽 인물의 안내 말풍선이 자동으로 표시됩니다. 안내에는 욕설이 포함되어 있습니다.
5. 입장 버튼을 누르면 안개가 화면을 덮은 뒤 메인 화면으로 전환되고 안개가 사라지도록 했습니다. 움직임 줄이기 설정에서는 애니메이션 없이 전환합니다.

## 확인 현황

JavaScript 구문과 오프닝 말풍선·타이머·화면 전환 로직을 확인했습니다. 실제 브라우저에서의 화면 배치, 애니메이션 및 전체 체험 흐름은 추가 확인이 필요합니다.
